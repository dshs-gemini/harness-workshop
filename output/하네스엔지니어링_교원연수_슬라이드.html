채팅 AI는 텍스트로 답을 돌려주고, Claude Code는 도구 호출로 작업을 직접 수행한다. 채팅은 결과를 내가 저장·실행하고 오류도 내가 다시 붙여넣어야 한다. Claude Code 안에서 !를 앞에 붙여 ! firebase login처럼 실행하는 방법은 문서에 브라우저가 열리는 명령의 동작이 명시되어 있지 않으므로 연수에서는 일반 터미널을 쓴다 확인 필요. 4분 중 1~2단계(콘솔 로그인 확인, firebase login)는 연수 전에 해 두면 더 여유 있다. 사람이 하는 일은 콘솔 로그인 확인, firebase login 허용, 이후 계획·명령 승인이고, 새 콘솔 작업은 없다. 배포는 공개 행위이므로 60번에서 계획을 읽고 승인한다. 보안은 한 문장: 60번에서 Claude Code가 로그인한 본인 uid 문서만 읽고 쓰는 firestore.rules를 함께 만들어 배포한다. 교사용 정답은 웹앱 파일에 넣지 않는다(페이지 소스로 보임). 이 구조는 Spark(무료)로 되고 Storage와 Cloud Functions(Blaze 필요)는 쓰지 않는다. 학생 응답은 콘솔 Firestore 데이터 화면에서 확인한다. 점검표
  1. 교과 내용·문항이 단원 학습 목표와 맞는가
  2. 로그인 없이 문항이 보이고 안내 문구가 이해되는가
  3. 글자 크기·접근성
  4. 개인정보와 정답이 페이지 소스에 없는가(오른쪽 클릭 > 페이지 소스 보기).

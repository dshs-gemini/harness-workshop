## 2. 남은 문제와 새로 찾은 불일치 (N1~N12)

N1·N3·N4·N5는 부분 반영 항목의 남은 부분이고, 나머지는 이번에 새로 찾은 것이다.

### N1 [높음] M7 슬라이드 50·51: "막힘 5개"가 남음
- 근거: `02_engineer_prompts.md` 0-0절 #4 "버튼 6을 **반드시 넣는다.** 기대 결과는 막힘 6개 + 열림 2개", 50절 표와 436줄 "원고에 함께 반영할 곳"; `02_engineer_rules.md` 9-1 "막힘 6개·열림 2개".
- 원고 상태 (`02_writer_M7_slides.md`):
  - 50 본문 2번째 줄 "막힘 5개가 나와야 성공이다"
  - 50 도식 아래 "막힘 5개 + 열림 2개가 기대대로면 성공"
  - 50 도식 "**강사가 추가해 둘 것**: 현재 점검 페이지에는 … 버튼이 없다 … (추가하면 막힘 6개 + 열림 2개)". 점검 페이지는 아직 없는 파일이고 엔지니어가 버튼 6을 필수로 정했으므로, "현재 없다"는 사실과 맞지 않는다.
  - 50 도식 번호: "6. 확인 버튼"이라 버튼 6을 넣으면 번호가 겹친다.
  - 50 예상 결과 "버튼 1~5를 누르면 …", "막힘 5개와 열림 2개"
  - 51 도식 3행 "(강사가 버튼 6을 추가했다면 버튼 6도 막힘)"
- 수정안:
  - 50 본문: "… 버튼을 하나씩 누른다. 막힘 6개, 열림 2개가 나와야 성공이다."
  - 50 도식: "6. 버튼 6 / 가입한 수업에 자료 1건 쓰기 / 막힘 / 원칙 3"을 넣고 확인 버튼을 7행으로 옮긴다. 아래 줄은 "막힘 6개 + 열림 2개가 기대대로면 성공". "강사가 추가해 둘 것" 문단은 "점검 페이지(버튼 1~6 + 확인 버튼)는 강사가 `02_engineer_prompts.md` 슬라이드 50 명세대로 만들어 `checkpoint-final`에 넣어 둔다" 한 줄로 바꾼다.
  - 50 예상 결과: "버튼 1~6을 누르면 … 막힘 6개와 열림 2개가 …"
  - 51 3행: "점검 페이지 버튼 3과 6 막힘"
  - M7 메모 4번째 줄(남은 `[확인필요]` 목록)은 바꿀 필요 없음.

### N2 [중] M7 슬라이드 50: 점검 사전 조건과 입력칸이 슬라이드에 없음
- 근거: prompts 50 명세 "사전 조건(짝 활동): 교사 역할이 수업 2개를 만들고, 학생 역할은 그중 하나(B)에만 가입하고 학습지 1개를 제출해 둔다", "입력칸 3개(① 가입하지 않은 수업코드, ② 가입한 수업코드, ③ 다른 학생 uid(선택))", 사전 확인을 통과하지 못하면 "점검 불가".
- 원고 50 노트는 "한 명은 교사 계정으로 수업을 준비해 코드를 알려 주고"뿐이다. 수업 2개, 학습지 제출, 입력칸 ②가 빠져 있다. 이대로면 버튼 1(미가입 수업 A 없음), 2·5·확인(학습지·제출물 없음), 6(가입 수업 코드 ② 없음)이 "점검 불가"로 나온다.
- 수정안: 50 도식 위에 "준비(1분): 교사 역할은 수업 2개(A, B)를 만든다. 학생 역할은 B에만 가입하고 B의 학습지 1개를 제출한다. 점검 페이지 입력칸 ①에 A, ②에 B 코드를 넣는다"를 넣는다. 노트에는 "모듈 5·6에서 쓴 수업을 B로 쓰고 A만 새로 만들면 1분 안에 된다"를 적는다. 50의 5분 안에 들어가는지는 강사 리허설에서 잰다.

### N3 [중] M2 슬라이드 13·17: "Firestore Database" 표기 (2-2 부분)
- 13 단계 1과 도식은 "데이터베이스 및 스토리지(Databases & Storage) > Firestore"로 고쳐졌다. 그런데 13 예상 결과는 "Firestore Database 화면에…", 17 프롬프트 1단계는 "콘솔 Firestore Database → 데이터 탭"이다. 공식 문서(1회차 2-2 근거) 표기는 "Firestore"이며, 같은 모듈 안에서 메뉴 이름이 둘이 되면 참가자가 다른 메뉴를 찾는다.
- 수정안: 13 예상 결과 "Firestore 화면에 빈 데이터 탭이 보이고 …". 17 단계 1 "콘솔 왼쪽 메뉴 데이터베이스 및 스토리지 > Firestore → 데이터 탭 → `users` 컬렉션 → 내 문서 클릭 `[확인필요: 리허설 캡처 - 한국어 메뉴 표기]`".

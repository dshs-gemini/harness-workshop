# HTML 슬라이드 덱 규칙

원고 형식은 `course-slide-authoring`을 따르고, 이 문서는 HTML 조립 규칙만 다룬다. 둘을 나누면 원고는 그대로 두고 표현만 바꿀 수 있다.

## 구조
- 파일 하나, 외부 스크립트·스타일·폰트 없음(연수장 인터넷이 불안정해도 열려야 한다). 시스템 한글 폰트 스택을 쓴다.
- 슬라이드는 `<section class="slide" data-kind="개념|실습|점검|정리" data-min="분">`. 고정 16:9 무대(1280×720)를 `transform: scale`로 창에 맞춘다.
- 슬라이드 상단에 모듈 이름과 `n / 전체` 번호, 하단에 진행 막대를 둔다.

## 조작 (바닐라 JS)
- `→ Space PageDown` 다음, `← PageUp` 이전, `Home/End` 처음·끝.
- `G`: 슬라이드 목차(그리드) 열기, `N`: 발표자 노트 토글, `F`: 전체화면(글자 키는 `e.code`로 인식해 한글 입력 상태에서도 동작), `P`: 인쇄용 전체 보기. 터치 스와이프 지원.
- URL 해시(`#12`)로 현재 슬라이드를 기억해 새로고침해도 유지한다.
- `@media print`에서 슬라이드마다 한 페이지로 출력해 PDF 배포가 가능하게 한다.

## 디자인 토큰
기존 가이드 문서 팔레트 DNA를 유지하고, 모든 값을 `:root` CSS 변수(토큰)로 정의해 하드코딩하지 않는다(생성기 `output/build_deck.py`의 `CSS`).
- 색 · 종이/잉크(따뜻한 중립): `--paper #f8f2e4` `--paper-hi` `--paper-2` `--paper-3`, `--ink #2a2314` `--ink-2` `--ink-3` `--ink-4`, 선 `--rule` `--rule-2`.
- 색 · 역할: `--accent #b0402c`(실습·경고·강조 한 곳), `--teal #356e67`(예상 결과·허용), `--blue #2f5f98`, `--ochre #8a6420`(점검·확인 필요), 각 `-2`(진하게)·`-wash`(옅은 바탕). 코드 패널 `--night #231d14` `--on-night`, 구문 `--sy-key` `--sy-head` `--sy-fm`.
- 트랙 톤 `--tone`: Track 1(M1–M3) 파랑, Track 2(M4–M5, M7) 청록, Firebase(M6) 황토, 마무리(MW) 강조색. 모듈 칩·레일·글머리·진행 막대가 톤을 따른다.
- 글꼴: 시스템 한글 스택(`Apple SD Gothic Neo`, `Malgun Gothic`, `Noto Sans KR`…)과 모노 스택만. 코드는 합자 끔. 숫자는 `tabular-nums`.
- 타입 스케일(무대 px): 표지 86, 모듈 번호 150, 제목 46(실습 42, 2줄 넘으면 34까지 자동), 리드 36, 본문 28–32(맞춤 계산 하한 24), 보조 20–22, 라벨 14–15(자간 넓게). 도식 SVG 글자 20 이상.
- 간격 `--s1..--s8`(4–64px), 좌우 여백 `--pad-x 64px`, 레일 `--rail 248px`. 모서리 `--r-s 3px` `--r-m 6px`(상자는 거의 각지게), 선은 머리카락 선(`--hair`)과 잉크 굵은 선(`--rule-ink`) 두 가지.
- 맞춤 계산(JS `fit`): 글자 변수 `--fs`(본문) `--fp`(프롬프트·코드) `--fr`(긴 결과 미리보기) `--fk`(예상 결과·막힐 때)를 넘친 열에 해당하는 것만 단계적으로 줄인다. `.mov`(예상 결과·막힐 때 상자)는 덜 찬 열로 옮겨 보고, 그래도 안 되면 막힐 때를 노트(N)로만 보낸다. 현재 슬라이드를 먼저 맞추고 나머지는 나눠서 계산한다.

### 레이아웃 템플릿(슬라이드 유형·내용으로 자동 선택, `L_*` 함수)
- `cover` 표지(어두운 바탕, 한 곳만 대담하게), `opener` 모듈 첫 슬라이드 왼쪽 레일(모듈 번호·시간·슬라이드 범위·학습 목표), `stmt` 개념 진술(번호+선 구분, 세로 가운데), `summ` 정리(큰 번호), `quest` 점검(황토 세로선 + 큰 질문, 오른쪽 활동), `split` 서술+시각물 분할, `stack` 리드+도식, `prac` 실습(왼쪽 단계 타임라인, 오른쪽 프롬프트·결과 화면, 예상 결과·막힐 때 상자), `prac heavy` 코드가 많은 실습(프롬프트 큰 열 + 결과 2단 미리보기), `console` Firebase 콘솔 설정(왼쪽 요점·결과, 오른쪽 번호 단계), `tbl` 표 중심, `brk` 휴식.
- 표 셀 줄바꿈: 셀 글이 짧은 표(모든 셀 30자 이하)는 표 전체에, 첫 열만 짧은 표(26자 이하)는 첫 열에 `white-space:nowrap`을 건다(`mark_nowrap_tables`, 클래스 `nw`·`nw1`). 괄호 하나 때문에 첫 열이 꺾이지 않게 하려는 규칙이며, 자리가 모자라면 맞춤 계산(JS)이 글자를 줄인다. `.ptbl`(고정 폭 표)은 자동 폭으로 바꾼다. 교재판(`build_handout.py`)은 영향을 받지 않는다.
- 도식은 슬라이드 번호별 `OVERRIDES`에서 인라인 SVG(`D` 작성기, 화살표 마커 `#ah-*`)나 HTML 구조로 그린다. 도식 안 글자는 원고 문장에서만 가져온다(새 사실 금지).
- 유형 배지: 개념(외곽선·원), 실습(강조색 채움), 점검(황토·마름모), 정리(잉크 채움). `확인 필요`는 황토 바탕 작은 배지. 코드 패널은 어두운 바탕 + 왼쪽 색 띠(입력=강조, 파일=청록) + 위쪽 라벨·복사 버튼.

## 컴포넌트
- `.prompt-box`: 붙여넣을 프롬프트. 복사 버튼 포함, 복사 대상은 첫 `<code>`.
- `.terminal`: 예시 세션 (`.term-you / .term-claude`).
- `.file-box`: 에이전트·스킬·CLAUDE.md 파일 예시.
- `.flow`: 화살표 도식(에이전트 팀 패턴, Firebase 데이터 흐름). CSS/SVG로 그린다.
- `.steps`: 콘솔 설정 단계(번호 큰 원 + 한 줄). 한 슬라이드에 5단계 이하.
- `.notes`: 발표자 노트(기본 숨김, N키).
- `<code>` 안의 `<`, `>`, `&`는 이스케이프한다.

## 검증
조립 후 모든 슬라이드를 캡처해 `.slide` 안에서 스크롤·잘림이 없는지 본다. 넘치면 슬라이드를 나눈다.

## 교재판 (인쇄용 A4 세로)
발표용 덱과 같은 원고에서 만드는 별도 산출물이다. 발표용 덱은 건드리지 않는다.

- 산출: `output/하네스엔지니어링_교원연수_교재.html`(+ 확인용 `.pdf`), 조립 스크립트 `output/build_handout.py`. 파서·인라인·블록 렌더 함수는 `build_deck.py`를 import해서 재사용한다(공용 함수의 동작을 바꾸지 않아야 하며, 덱의 디자인 층을 고친 뒤에는 교재 HTML 해시가 같은지 비교한다).
- 판형: `@page { size: A4; margin: 18mm 16mm 20mm }`, 흰 종이, 본문 10.5pt/행간 1.65, 해설 9.5pt, 코드 8.5pt. 제목은 명조 스택, 본문은 고딕 스택(시스템 폰트, 외부 폰트 없음). 코드는 합자(ligature)를 끈다(`!=`가 `≠`로 보이는 것 방지).
- 색: 강조 `#b0402c`, 보조 `#356e67`만 절제해서 쓴다. 코드·프롬프트·파일·터미널 상자는 연한 회색 바탕 + 왼쪽 강조선(검은 배경 금지). 유형 배지는 색이 없어도 구분되게 채움/외곽선/이중선/검정으로 달리한다.
- 구성: 표지, 사용법, 목차(모듈·슬라이드별 쪽 번호), 모듈 도입 쪽(학습 목표·시간·산출물·슬라이드 표), 슬라이드 블록. 블록 순서는 번호·제목·유형 배지 → 본문 → 도식·단계 → 프롬프트·파일 → 예상 결과 → 막힐 때 → 해설(발표자 노트) → 실습·점검이면 체크 칸과 메모 줄.
- 쪽 규칙: 표·코드 상자·실습 단계 `break-inside: avoid`, 제목·소제목·`소요 시간` 줄 `break-after: avoid`, 코드 상자 앞 안내 문장은 상자와 붙인다. 모듈마다 `@page` 이름(`.m-M1` 등)을 두어 러닝 헤더에 모듈명, 푸터에 쪽 번호를 넣는다(Chrome 131+ 쪽 여백 상자).
- 유지할 표시: `[확인필요]`는 작은 윗첨자식 점선 밑줄 표시 + 해설 아래 항목 목록, `[화면 캡처 자리]`·`[설문 링크/QR]`는 점선 상자.
- 쪽 번호는 2회 조립: HTML → Chrome PDF → 슬라이드별 첫 쪽 추출(`슬라이드 n / 74`, `MODULE Mx` 문구) → 목차에 채워 재조립. Chrome 헤드리스가 PDF를 쓰고도 종료하지 않는 경우가 있어 파일 크기가 안정되면 프로세스를 끝낸다.
- 검증: 슬라이드 74개 대응 블록의 누락·중복, 코드·표 가로 넘침(DOM 검사), 대표 쪽과 M6 구간 쪽 이미지 확인(제목 고아·표 분리), 흑백 변환 대비, 쪽 수와 실제 글자 크기를 보고한다.

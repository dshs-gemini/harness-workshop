# 연수 슬라이드 작성 규칙

## 원고 파일 형식
슬라이드 하나는 아래 블록으로 쓴다. 조립 단계가 이 형식을 파싱하므로 키를 바꾸지 않는다.

```
## [슬라이드 N] 제목
- 유형: 개념 | 실습 | 데모 | 정리
- 본문: (3줄 이내 핵심 문장)
- 도식: (필요하면 그릴 내용 설명, 없으면 생략)
- 프롬프트: (실습일 때 Claude Code에 붙여넣을 문장 전체)
- 예상 결과: (실습일 때 화면에 보여야 할 것)
- 막힐 때: (흔한 오류 1~2개와 해결)
- 노트: (발표자 대본, 소요 시간)
```

## 규칙과 이유
- 슬라이드 하나에 메시지 하나. 청중이 읽는 동안 발표자 말을 놓치지 않게 하기 위해서다.
- 본문 글자는 24pt 이상으로 가정하고 문장을 줄인다. 연수장 뒷자리에서 읽혀야 한다.
- 개념 슬라이드 3장마다 실습 또는 질문 슬라이드를 둔다. 집중이 끊기기 전에 손을 움직이게 한다.
- 실습은 "프롬프트 → 결과 확인 → 막힐 때" 순서로 쓴다. 코드가 아니라 요청 문장을 보여준다.
- 전문 용어는 처음 나올 때 정의와 동작 원리를 한 줄로 쓴다. 청중이 정보교사이므로 비유는 쓰지 않는다.
- 확실하지 않은 사실은 `[확인필요]`를 붙인다. 추측으로 메뉴 이름을 쓰면 연수 현장에서 막힌다.
